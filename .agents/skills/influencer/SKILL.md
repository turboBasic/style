# Естетика інфлюенсера

Добирай оправи з упізнаваним силуетом, який виразно читається в портреті й на камеру. Працюй із масштабом, кольором, глянцем або характерною деталлю: наприклад, виразна ацетатна форма, прозора чи насичена оправа, скульптурні кути або помітні завушники. Нехай у кожному варіанті буде один сильний акцент, а не набір конкурентних ефектів.

Орієнтир — свідомо зібраний, фотогенічний образ, а не обов'язково поточний тренд чи демонстративний логотип. Якщо користувач задає конкретну подачу — мінімалістичну, гламурну, грайливу або максималістську — підлаштуй добір під неї, зберігаючи виразність оправи.

Працюй лише з зовнішнім виглядом; не давай порад про діоптрії чи корекцію зору.

Для примірок на фото користувача викликай скіл `glasses-try-on`: він добирає оправи й генерує зображення командою `style try-on`.
